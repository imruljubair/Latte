THE FULL LOCAL VERSION

Make the corpus your own.

Train a small language model with your own text and architecture. The Training tab shows live training and validation curves; the Explorer reveals the calculations behind recorded updates.

1. Get Latte

Install Python 3.11 or newer (Python 3.12 is tested). Download the source ZIP from GitHub, or clone the repository:

git clone https://github.com/imruljubair/Latte.git
cd Latte

Source on GitHub ↗ · Download source ZIP

2. Start Latte

On macOS or Linux:

./start

On Windows, or without the shell launcher:

python launch.py

The launcher creates a local Python environment, installs dependencies, prepares an example recording, and opens the app. Internet access is needed for the first setup. The built frontend is included, so Node.js is not needed.

Open http://127.0.0.1:8000/ if the browser does not open. Keep the terminal running; stop with Ctrl+C.

3. Train and explore

Open Training, paste your corpus, choose architecture and training settings, and select Start training. Once records are ready, open the run in Explorer. Click Apply update to compare a recorded weight update; enable Math to inspect formulas and trace their operands.

Training runs locally on CPU. Runs, checkpoints, and standalone HTML exports stay in your local out/ folder.

If something does not start

If port 8000 is occupied, use ./start --port 8080. If Python is missing or too old, install Python 3.12 and reopen the terminal. On macOS or Linux you can choose it explicitly with LATTE_PYTHON=python3.12 ./start.
